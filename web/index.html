找到你的節奏
每局 10 題。逐字輸入畫面上的英文單字，輸入最後一字即自動判分。錯字會記錄，但不會讓游標前進；不必退格或按 Enter。
  1. 開始 / BTN 1：開始新局，或從暫停繼續。
  2. 暫停 / BTN 2：凍結倒數並讓燈號恆亮，再按繼續。
  3. 燈色 / BTN 3：綠、黃、紅循環展示，不影響計分；換題恢復自動燈色。
  4. 速率 / BTN 4：8 / 5 / 3 秒切換，呼吸週期同步加快；當題剩餘比例保留。
剩餘時間 >60% 得 7 分、30–60% 得 5 分、<30% 得 3 分，逾時 0 分並換題。暫停時間不計入 WPM；正確率為正確字元 / 所有輸入字元。
接板模式由 STM32 控制遊戲；請先燒錄韌體，再用資料 USB 線連到板上 ST-LINK USB。練習模式只模擬畫面，不代表實體硬體驗證。
