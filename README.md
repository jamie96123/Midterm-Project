# Lab4 三色燈控制

Current website: /web/ — LPUART1 115200 8N1, plain text commands and PC3/PC4/PC6 LED outputs.
Firmware: downloads/TypeRush-Lab4-LED.zip. Setup: downloads/Lab4/README.md.
Uses the supplied Lab4 PPT method: HAL single-byte interrupt receive, 256-slot ring buffer, 200ms main-loop delay.
The previous TypeRush typing game is retained at /typing-game/.
GitHub Pages: gh-pages branch, / (root). No build or external runtime dependencies.
